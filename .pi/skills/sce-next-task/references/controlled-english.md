# Controlled English

Controlled English is a writing discipline for SCE plans and durable context. It
is not a strict implementation of ASD-STE100. Apply these rules to new or
modified prose.

## Rules

- Write short, direct sentences. Express one requirement, instruction, or
  factual statement at a time.
- Use consistent terminology. Prefer established technical terms over synonyms.
  Define ambiguous terms when necessary.
- Use active voice when the actor is known. State prerequisites and conditions
  explicitly.
- Use `must` for requirements, `should` for recommendations, `may` for
  permissions, and `can` for capabilities. Preserve the intended strength of
  each statement.
- Make requirements testable. Specify observable behavior, constraints, and
  relevant failure conditions.
- Preserve technical meaning, identifiers, commands, evidence, and Markdown
  structure. Do not rewrite unrelated content solely for style.
